# Déclarations de développement

Ces trois fichiers visent le serveur himjlean lancé sur le poste (`npm run dev` avec `HIMJLEAN_MCP_LOCAL=1`) et les applications OAuth du projet Supabase de Dev. La marketplace ne les installe pas : pour tester en local, recopier le bloc voulu dans sa propre configuration (Codex, Claude Code ou OpenCode) à la place de la déclaration du plugin.

Le site les lit aussi pour afficher le guide d'installation en développement.
